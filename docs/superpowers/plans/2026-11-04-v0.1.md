# v0.1 implementation plan

Goal: Deliver issue #1 with reproducible evidence and two reviewable PRs.
Architecture: ESM command dispatcher, focused filesystem, scan, execution, Markdown,
verification, art and delivery modules. Work products stay in the user cache;
only authored assets and reproducible specs go in target repositories.
Stack: Node >=20, node:test, Playwright, marked, github-slugger. No build.

Constraints: Never merge, publish, change settings or push a default branch.
Use private word scan before every commit. Preserve unrelated work. Execute
README commands only in disposable copies; these copies are not OS sandboxes.
Use user-approved noninteractive G1/G2 decisions recorded in brief.json.

and push. Open draft early; mark ready only after all acceptance evidence passes.
