Order of the homepage:
1. Name as H1; then the chosen one-liner in bold plus one sentence of what it does.
2. At most 3 badges (CI, license, version) and the language switch link.
3. Hero image with descriptive alt text.
4. Install command in its own sh block (one line). For agent skills, follow it with "Then tell your agent:" and a quote of a realistic request, using placeholders like `<url>`.
5. One line of requirements: runtime, API key yes/no, hosted service yes/no.
6. "Why this one": 3 bullets, bold lead + one or two sentences, then the alternatives table.
7. "Try it": the shortest real path, every line runnable as written.
8. Modes or key options in at most 3 bullets, each linking into docs/reference.
9. Scope and rights: one plain sentence, legal detail folded in <details>.
10. Contributing and license in two lines.

Rules: no emoji headers, no badge walls, no file trees, no per-file summaries. Use plain words. Every claim must trace to a file. Commands must work when copied (no OWNER/REPO). Keep the first four items within 800px on a 1280-wide screen.
